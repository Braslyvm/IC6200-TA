# Algoritmo A*

## Descripción del algoritmo

se impleneta la búsqueda A* para encontrar una ruta desde un punto inicial hasta un punto final dentro de una matriz.

El algoritmo utiliza la distancia Manhattan como heurística para estimar qué tan cerca está un nodo del destino. Además, toma en cuenta la cantidad de pasos recorridos, seleccionando siempre el camino con menor costo estimado.


---

## Instrucciones de instalación

1. Tener instalado **Python 3** en la computadora.

2. Tener instalado **pygame** para poder ejecutar la interfaz gráfica.


## Instrucciones de ejecucion

### Archivo


```bash
python3 A*.py
```
### interfaz

```bash
python3 Interfaz.py
```
