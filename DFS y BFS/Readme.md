# Busqueda en grafos (Anchura y Profundidad)

## Descripción del algoritmo

se implementan dos algoritmos de búsqueda en grafos: búsqueda por anchura y búsqueda por profundidad.

la búsqueda por anchura recorre el grafo nivel por nivel utilizando una cola, garantizando encontrar el camino más corto en términos de número de nodos.

la búsqueda por profundidad recorre el grafo de forma recursiva explorando cada rama hasta el fondo antes de retroceder, almacenando los posibles caminos encontrados.

---

## Instrucciones de instalación

1. Tener instalado **Python 3** en la computadora.
2. Tener instalado **tkinter** para poder ejecutar la interfaz gráfica.
